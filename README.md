# Aidly - Smart help, close to home 💚

ברוכים הבאים ל-Aidly! 
פרויקט גמר - מערכת קהילתית לסיוע לאזרחים ותיקים במטלות בית קטנות ולא-רפואיות (כגון החלפת נורה, הזזת חפצים כבדים וכו'), על ידי חיבורם למתנדבים מקומיים.

## 🛠️ טכנולוגיות
* **צד לקוח (Frontend):** React.js, Vite
* **צד שרת (Backend):** Node.js, Express
* **מסד נתונים (Database):** Microsoft SQL Server

---

## ⚙️ הוראות התקנה והפעלה (Setup Guide)

### דרישות קדם (Prerequisites)
* Node.js מותקן על המחשב.
* Microsoft SQL Server מותקן ורץ (או חיבור למסד נתונים בענן).

### שלב 1: הגדרת מסד הנתונים
1. פתח את SQL Server Management Studio (SSMS).
2. ודא שיש לך את בסיס הנתונים של הפרויקט.
3. נווט לקובץ `backend/db.js` וודא שפרטי החיבור (Connection String) מעודכנים בהתאם לשרת ה-SQL המקומי או המרוחק שלך.

### שלב 2: הפעלת צד השרת (Backend)
1. פתח חלון טרמינל (Terminal) ונווט לתיקיית השרת:
   ```bash
   cd finalProject-master/backend
התקן את התלויות:

Bash
npm install
הפעל את השרת:

Bash
node server.js
השרת אמור לרוץ ולהציג הודעה על חיבור תקין למסד הנתונים.

שלב 3: הפעלת צד הלקוח (Frontend)
פתח חלון טרמינל נוסף ונווט לתיקייה הראשית של הפרויקט:

Bash
cd finalProject-master
התקן את התלויות:

Bash
npm install
הפעל את אפליקציית ה-React:

Bash
npm run dev
פתח את הדפדפן בכתובת שמופיעה בטרמינל (לרוב http://localhost:5173).

📖 מדריך למשתמש (User Guide)
המערכת מבוססת על מודל הרשאות (Role-Based) ומציגה ממשק מותאם אישית לכל סוג משתמש לאחר ההתחברות (Login):

👴 אזרח ותיק (Senior)
יצירת בקשה: במסך הבית, לחצו על Request New Help Now.

מילוי פרטים: בחרו את סוג העזרה הנדרשת (למשל: קניות, עזרה טכנית), הגדירו את רמת הדחיפות (High, Medium, Low) והוסיפו הערות אם צריך.

שליחה: לחצו על Send Request. הבקשה תעבור לסטטוס "Waiting" עד שישובץ אליה מתנדב.

🧑‍💼 מנהל מערכת (Admin)
אישור מתנדבים (Vetting): היכנסו ל-Pending Approvals ב-Dashboard. כאן תוכלו לראות מתנדבים חדשים שנרשמו, ולאשר (Approve) או לדחות (Reject) אותם.

הקצאת משימות (Matching): היכנסו ל-Request Queue. כאן תוכלו לראות את כל הבקשות הממתינות של הקשישים. בחרו מתנדב פנוי מהרשימה הנפתחת ולחצו על Save כדי להקצות לו את המשימה.

🤝 מתנדב (Volunteer)
קבלת משימה: במסך ה-Volunteer Dashboard, תחת "My Active Tasks", תוכלו לראות משימות שהוקצו לכם עם כל הפרטים (שם, טלפון, כתובת).

סיום משימה: לאחר ביצוע העזרה, לחצו על Mark as Complete ✅.

משוב (Feedback): לאחר סיום המשימה, המערכת תעביר אתכם למסך משוב (Survey) בו תוכלו לדרג את החוויה שלכם מול האזרח הוותיק (1-5 כוכבים) ולהשאיר הערות.

פותח על ידי: אבראהים עיאד ומאלק ספורי
